# QQ AI Voice Bridge - Rules

Stack: Python 3.10+ AstrBot plugin, aiocqhttp/NapCat, `pilk`.

## Git

- Work on `feature/initial-implementation`; never commit to `main` directly.
- Micro-commit each logical step with Conventional Commits.
- Never add AI co-author trailers or mention AI in commit messages.

## Workflow

1. Locate the task in `TODO_WORKFLOW.md`; mark it `[IN PROGRESS]`.
2. Read `SOURCE_OF_TRUTH.md` and the relevant architecture section before edits.
3. Update the docs first when an architectural fact changes.
4. Mark tasks `[FINISHED - PENDING MERGE]` before review and `[MERGED/DONE]`
   after integration.

## Reference Precedence

1. Apex truth: `SOURCE_OF_TRUTH.md`.
2. Architecture and phases: `ARCHITECTURE_ROADMAP.md`.
3. Tasks: `TODO_WORKFLOW.md`.
